# AI 伴侣 · AI Companion

限制最少的 Android 角色扮演前端。数据在你手机上，模型你自己接，客户端不加任何内容审查。

[![Build APK](https://github.com/RT-C-6668882025/ai-chat/actions/workflows/build.yml/badge.svg)](https://github.com/RT-C-6668882025/ai-chat/actions/workflows/build.yml)

---

## 快速开始

到 [Releases](https://github.com/RT-C-6668882025/ai-chat/releases/latest) 下载 `app-debug.apk` 安装，需要 Android 10（API 29）及以上。装好后进设置填 API Key 即可开聊。

之后不用再回来：应用内 **设置 → 关于 → 检查更新** 会自动读取最新 Release。

自己构建：

```bash
./gradlew :app:assembleDebug
```

产物在 `app/build/outputs/apk/debug/`，需要本机装好 Android SDK（compileSdk 36）。

## 功能

### 对话

- 消息树：重新生成不覆盖旧回复，长出兄弟分支，气泡右下角 `‹2/3›` 随时切换。
- 时光倒流：从历史里任意一句重新开始，之后的对话保留为另一条分支。
- 多气泡：模型用 `|||` 分隔可连发多条短消息。
- 心声：`<inner>` 标签内的内容作为角色没说出口的想法单独展示。
- 括号指令：`（好感度+10）` `（天气=雨）` 这类直接改变量，本地处理，不消耗 API 调用。中英文括号都认。
- 其余括号交给模型判断是动作、场景、变量、人设修改还是要记住的事，再调对应工具。判断失败一律退回当动作处理，不会误改存档。可关。
- 人设修改是追加到「补充设定」，不覆盖原有角色设定。
- 变更记录：变量、场景、人设、记忆的每一次全局修改都记下来，可逐条撤销；撤销会覆盖后续变更时先提示。
- 沉浸模式：全屏、文字逐字浮现、点击跳过。
- 消息改写、重新生成、复制、删除。
- 流式输出，可关。

### 记忆

- 对话自动提炼成记忆事件。
- 记忆带权重衰减，注入 prompt 时按 Top-K 挑选。
- 衰减到阈值以下停止注入，数据不删除，可在面板里恢复或置顶。
- 改写消息会把相关记忆标记为待更新。
- 衰减速率、注入条数、总结间隔均可调。

### 剧情

- 剧情是分支图，不是单线：节点带台词与指引，边分选项边、条件边、关键词边、自动边。
- 变量赋值挂在节点上，条件边按变量值决定走向。
- 多结局，解锁后进结局图鉴。
- AI 生成世界观：填题材、年代、基调，产出背景与开场情境。
- AI 生成剧情线：填想讲的故事，产出整张分支图（节点、选项、变量、多结局）。
- 生成结果先做结构校验，不合法直接丢弃。

### 养成

- 好感度：范围 -100~200，分初识 / 熟悉 / 亲近 / 深交四个阶段，阶段会影响角色语气。
- 里程碑：8 个好感度阈值，跨过时把角色当时那句话做成纪念卡。
- 每日心情：每个角色每天一个心情，当天稳定，影响说话语气。
- 连续陪伴：进对话自动签到，记连续天数与累计天数。
- 成就：18 条，老存档继续用会自动补齐已达成的。
- 纪念册：时间轴聚合里程碑 / 结局 / 成就 / 置顶记忆，未解锁成就显示灰色剪影。

### 提示词

- 点角色头像（主页卡片或聊天顶栏）直接开编辑器，角色设定 / 补充设定 / 开场白就地改。
- 每一处都有「AI 帮我改」：说一句「更毒舌一点」，模型重写，结果先预览再决定采用。
- 全局提示词模板可改，支持 mustache 风格的 `{{变量}}`、`{{#if}}`、`{{#each}}`。
- 模板改坏了（占位符丢失）会被拒绝保存。
- 提示词市场内置四个来源：Awesome-Prompts、ChatGPT Prompts、DSH 角色扮演、SillyTavern。
- 支持粘贴导入与自定义 URL 导入。
- 市场列表抓一次就缓存本地，刷新失败时保留旧缓存。

### 其他

- 双协议：`openai` 兼容与 `anthropic`，任选。
- 四路模型分工：对话、记忆总结、语义判定、指令生成可分别指定模型。
- 暖阳（亮）与星夜（暗）两套完整配色，44 个语义色 token，可跟随系统或手动指定。
- 整包导出 / 导入，按 id 合并。
- 应用内检查更新与下载安装。
- 12 个页面，单 Activity 手写页面栈，带转场动画与返回栈。
- 崩溃日志本地兜底。

## 比其他方案好在哪

| | 本项目 | SillyTavern | 端侧离线推理类应用 |
|---|---|---|---|
| 形态 | **Android 原生** | 桌面 / 本地浏览器服务 | Android 原生 |
| 数据 | 本机 | 本机 | 本机 |
| 模型 | **你接的 API / 局域网端点** | 同左 | 手机内推理 |
| 内容策略 | **客户端零审查** | 客户端通常不审 | 客户端不审，能力受端侧模型限制 |
| 适合 | 手机上自由聊，想用更强的云端或家用机模型 | 桌面深度玩法、扩展生态 | 断网、完全不出网 |

优点：

- **手机原生，不用开电脑挂服务。** SillyTavern 要跑一个本地服务再用浏览器连；这里装个 APK 就能用。
- **客户端不过滤提示词与回复。** 不拦截、不改写用户设定、不对回复做安全重写。成人向、原创设定、长线养成，只要模型肯写，前端不挡。
- **模型自备，上限不锁在手机算力上。** 可以接 DeepSeek / Qwen / Kimi / 硅基流动等云端端点，也可以指向自己的 Ollama 或家用机反代。
- **数据全在本机 JSON，可整包导出。** 不依赖本项目的任何云账号，卸载前导出就能带走。
- **养成与剧情图是内建的。** 好感度、里程碑、成就、分支剧情开箱即用，不用靠插件拼。

## 不足

- **不是端侧推理。** 必须联网到你配置的端点，没有 API Key 就用不了。「本地」指的是数据本地。
- **客户端不审，不等于一定能写。** 如果你用的是带安全策略的官方 API，拒答仍然来自模型方。要最大限度的自由，请自行指向本地模型或相应兼容端点。
- **危机关键词会多显示一条求助热线，且不可关闭。** 这是客户端唯一主动加的东西：只是多显示一条提示，不拦截消息、不改写 prompt、不过滤回复。
- **没有端到端 API 联调。** 需自备真实 Key 验证。
- **主动消息只在进入会话时按时间间隔触发**，没有后台推送。
- **多角色只支持故事内多 speaker + 旁白**，没有真正的多人群聊。
- **GitHub 未认证 API 限流 60 次/小时。** 已用本地缓存规避，但首次抓取或频繁刷新仍可能撞上。
- **只有 debug 签名的构建，未上架任何应用商店。** 签名用的是安卓公开约定口令，不提供任何安全保证，不可用于正式分发；不同密钥签的 APK 无法互相覆盖安装。
- **工程债：** `MainActivity.java` 单文件 6382 行，仓库目前零测试。

## 配置

首次启动会引导填 API 配置，之后在设置里改。

| 项 | 说明 |
|---|---|
| API 模式 | `openai`（OpenAI 兼容）或 `anthropic` |
| Base URL | 默认 `https://api.deepseek.com`。DeepSeek / Qwen / Kimi / 硅基流动 / Ollama 等兼容端点都能填 |
| 模型分工 | `main` 对话、`memory` 记忆总结、`judge` 语义判定与括号指令分类、`command` 指令生成，可分别指定，留空回落到 main |

设置里还能调：流式开关、历史窗口长度、记忆参数（总结间隔 / 注入条数 / 衰减速率 / 淡出阈值）、多气泡上限、心声与变量开关、主动消息间隔、主题。

括号指令有两个开关：**AI 判断括号指令**默认开，只对正则分不了类的括号生效，一回合最多多一次调用；**也判断 AI 回复里的括号**默认关，开了之后每条带括号的回复都会多一次分类调用。

填完可以点「测试连接」当场验证，也可以点「选择」浏览端点提供的模型列表。

## 数据与隐私

- 角色、对话、记忆、剧情、存档全部存在应用私有目录的 JSON 文件里，不上传任何服务器。
- 对话内容直接发往**你自己配置的 API 端点**，本项目不经手、不中转。
- 崩溃日志同样只写本地。
